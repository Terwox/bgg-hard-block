# Code of Conduct

This is a small project. The rules are correspondingly short.

## Expected behavior

Be civil and stay on topic. Assume the person you're replying to is acting in
good faith. Critique code, not people. Accept that the maintainer may decline a
feature without that being a personal judgment of you.

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Discriminatory or demeaning comments about anyone
- Publishing others' private information
- Sustained disruption of issues or pull requests
- Using this repository to conduct or continue a dispute from BoardGameGeek

That last one is specific to this project and worth stating plainly. BGG Hard
Block exists because people sometimes need distance from other users. This
repository is not a venue for adjudicating who deserved to be blocked, naming
particular BGG users as bad actors, or continuing an argument that started on a
forum thread. Bug reports should describe markup and behavior, not people.

## Scope

This applies to issues, pull requests, commit messages, and any other project
space.

## Enforcement

Report problems to terwox@gmail.com. Reports are handled privately.

The maintainer may edit or delete comments, close issues or pull requests, and
block accounts. There is no appeals process; this is one person's hobby project,
not an institution. Where a situation is ambiguous, expect the decision to favor
whoever is trying to use the software over whoever is arguing about it.
